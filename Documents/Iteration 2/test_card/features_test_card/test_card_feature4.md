# Feature 4: Smart Search & Discovery Engine

## Hypothesis

We believe that university students struggle to discover relevant courses because current search tools only allow student to navigate courses by course code or title. Students failed to search courses by skills that they want to developed or the careers they are targeting. Hence, we propose that a search engine allowing students to search by skill (e.g. "Python") or career (e.g. "Data Analysis", "Penetration Tester")m with basic filters like semester availability. This feature will significantly help students find more relevant courses and encourage skill-driven enrolment decisions.

## Test

To verify this hypothesis, we will conduct 3 interviews per team member with university student. Inteviews will focus on how students currently discover and search for courses, and their respond to the concept of a skill-based and career-driven search tool.

## Metrics

We will measure the following:

1. Discovery behaviour: How students currently search for and find courses (by code, course title, word of mouth, etc.)
2. Perceived usefulness: Do students think searching by skill or career would help them find more relevant courses?
3. Clarity: Can students easily articulate a skill or career they would search for?
4. Behaviour Change: Would students use this tool as their primary starting point when selecting courses?

## Criteria

We will consider the hypothesis validated if the following criteria are met:

- $70$% or more students express interest in being able to search for courses by skill or career keyword.
- $60$% or more students say the tool would be helpful for them to find more relevant courses than current search methods.
- $50$% or more students say they would use skill/career search as their primary starting point at enrolment time.

## Interview Questions

Therefore, we will ask

1. **Have you ever tried to find a course specifically because you wanted to learn a certain skill — for example, data analysis or public speaking?**
   - What did you search for, and did you find what you were looking for?
   - If the search didn't work well, what did you do instead?

2. **When you read a course title like "ENGG3400: Systems Thinking," can you tell from the title alone what skills you would actually develop?**
   - How often does that uncertainty affect whether you end up enrolling in a course?
   - Would being able to search by skill instead of title change how you browse for courses?

3. **Imagine you can type "Python" or "UX Design" into a search bar and instantly see every course that teaches that skill. How useful would that be for you?**
   - Is there a specific skill you would search for right now if that tool existed?

4. **Have you ever worked backwards from a career goal — for example, deciding you want to be a product manager and then trying to figure out which courses would get you there?**
   - How confident are you that your current course choices are actually moving you toward that career goal?

5. **If a search result showed you courses matched to a career like "Software Engineer," what information would you need to see to trust that the match is accurate?**
   - Is there anything that would make you distrust or ignore those results entirely?

6. **If a skill-based course search tool existed at your university today, how likely would you be to use it at the start of each enrolment period?**
   - What would make you recommend it to a friend who is struggling to pick courses?
